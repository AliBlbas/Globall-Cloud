# ڕێنمایی پارێزراوی بەستنەوەی هەژماری کڕیار — Globall Cloud

**بەرواری پشکنین:** ١٦ی ئۆکتۆبەری ٢٠٢٦  
**لق:** `Product`  
**مەبەست:** بەستنەوەی تۆماری کڕیاری کۆن بە Supabase Auth، بەبێ گۆڕینی خۆکاری داتای بار و دارایی.

ئەم ژمارانە تەنها کۆی گشتییە؛ هیچ ناو، ژمارەی مۆبایل، ئیمەیڵ، یان زانیاریی شەخسی لەم ڕاپۆرتەدا نیشان نادرێت. ژمارەی مۆبایل تەنها بەڵگەی تەواوی ناسنامە نییە؛ کۆدی GC و پشتڕاستکردنەوەی کڕیار پێویستن.

## پرۆسەی جێبەجێکردن

### ١. تاقیکردنەوە بە تەنها یەک کڕیار

1. بە هەژماری **Super Admin** بچۆ ژوورەوە: https://globall-cloud.pages.dev/staff-os-v5
2. لە ناوبەرەکە **کڕیاران** بکەرەوە.
3. لە فلتەری دۆخ، **«بێ هەژمار (چالاک)»** هەڵبژێرە.
4. تۆمارێک هەڵبژێرە کە GC Code ـەکەی بە کڕیارێکی دیاریکراو دڵنیایە و زانیارییەکانی پێداچوونەوەیان بۆ کراوە.
5. لەو ڕیزەدا دوگمەی **«هەژمار»** بەکاربهێنە. سیستەم پێش دروستکردن پشتڕاستکردنەوە داوا دەکات.
6. بۆ وشەی نهێنی، دەتوانیت بەتاڵی بهێڵیتەوە بۆ ئەوەی سیستەم وشەیەکی کاتی دروست بکات. وشەی نهێنیی کاتی بە شێوەی پارێزراو بپارێزە؛ لە گروپی گشتی یان تێبینییەکی ئاشکرا تۆماری مەکە.
7. بە کڕیارەکە بڵێ بە GC Code و وشەی نهێنی بچێتە ژوورەوە لە https://globall-cloud.pages.dev/dashboard، پاشان وشەی نهێنییەکەی بگۆڕێت.
8. پێش بەردەوامبوون، دڵنیابە ناوی پڕۆفایل و بار و فاکتورەکان تەنها بۆ هەمان کڕیار پیشان دەدرێن؛ کۆی Auth-linked ـیش پێویستە زیاد ببێت.

### ٢. ١٤٨ تۆمارەکە کە ژمارەی مۆبایلیان هەیە

ئەم کڕیارانە بۆ پشکنینی سەرەتایی باشترن، بەڵام پێش بەستنەوە:
- GC Code لەگەڵ تۆماری دروست بگونجێت.
- ژمارەی مۆبایل بە کڕیارەکە پشتڕاست بکرێتەوە.
- لە دوو باری ژمارەی مۆبایلی دووبارەبووەوە، ناسنامە و تۆماری کڕیار بە وردی دڵنیایی لێبکرێتەوە.

### ٣. ٦٧٠ تۆمارەکە کە ژمارەی مۆبایلی بەکارهێنراویان نییە

پێش بەستنەوە، ژمارەی مۆبایل لە کڕیار یان سەرچاوەی کۆن و پشتڕاستکراو وەربگرە و لە پەڕەی کڕیاراندا نوێی بکەرەوە. ژمارەی پێشبینی‌کراو یان داتا لە تۆمارێکی تر وەرمەگرە. ئەگەر کڕیار بە شێوەی باوەڕپێکراو لە ئۆفیس ناسرایەوە، Super Admin دەتوانێت هەژمارەکەی بە کردارە پارێزراوەکەی `account-admin` دروست بکات و GC Code + وشەی نهێنیی کاتی بە تایبەتی پێی بگەیەنێت؛ ئیمەیڵی ناوخۆیی دەتوانێت لە پشتەوە بەکاربهێنرێت، بۆیە کڕیار دەتوانێت بە GC Code بچێتە ژوورەوە.

## پاراستن و تاقیکردنەوە

- هەژمارەکان بە SQL یان لە ڕێگای خۆکاری bulk مەبەستەوە مەبەستەوە؛ کردارەکانی Super Admin لە `account-admin` بەکاربهێنە تا چاودێری کردارەکان بمێنێتەوە.
- هەژمارەکانی کڕیار بە یەک جار دروست مەکە. یەک تاقیکردنەوە بکە، فلتەری Auth-linked و پۆرتاڵی کڕیار بپشکنە، پاشان هەنگاو بە هەنگاو بەردەوام بە.
- هیچ وشەی نهێنی لە GitHub، کۆدی پەڕە، تێبینییە گشتییەکان یان چاتێکی هاوبەشدا مەخە.
- هیچ رێکخستنی RLS، policy، role یان Supabase security بەبێ پشکنینی جیاواز مەگۆڕە.
- دوای بەستنەوە، لە هەژماری کڕیار دڵنیابە shipment، invoice، balance، پەیام و بەڵگەکان تەنها بۆ ئەو هەژمارەیە.

## دۆخی تاقیکردنەوەی مۆبایل

ستایل و script ـی ناوبەری مۆبایل لە `Product` تۆمار و لە Cloudflare بڵاو کراوەتەوە. بەڵام ئامرازی QA ـی براوزەر وایدثی مۆبایلی 375px پیشان نەدا؛ بۆیە تاقیکردنەوەی کۆتایی لە iPhone لەسەر سایتە زیندووەکە هێشتا پێویستە. تا ئەو پشکنینە نەکرێت، ناوبەری مۆبایل بە «١٠٠٪ پشتڕاستکراوە» ناناسرێت.
