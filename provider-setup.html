01 / DECISION

بڕیاری architecture

REST API ـەکان بە شێوەی server-side لە Supabase Edge Function ـەوە بانگ دەکرێن؛ MCP تەنها کاتێک بەکار دێت کە MCP server ـی ڕاستەقینە هەبێت.

WhatsApp Cloud API

Meta Graph API بە approved template، webhook ـی signed و delivery status بۆ WhatsApp.

Gmail API + OAuth 2.0

ناردنی MIME message بە `users.messages.send` بە کەمترین scope ـی `gmail.send`.

Meta app و WhatsApp Business Accountلە API Setup ـدا test number ID و business account ID وەربگرە؛ بۆ production token ـی کاتی بەکارمەهێنە.

03
Template ـی پەسەندکراوبۆ پەیامی business-initiated template ـی approved بە ناو و language ـی exact بەکاربهێنە.

03 / GMAIL

ڕێکخستنی Gmail API

Google Cloud project دروست بکە، Gmail API enable بکە و OAuth Web application بە redirect URI ـی environment ـەکەت ڕێکبخە.

کەمترین scope

تەنها ئەمە بەکاربهێنە: https://www.googleapis.com/auth/gmail.send. refresh token لە secret manager هەڵبگرە.

Server-side OAuth

authorization code بگۆڕە بۆ access/refresh token. client secret و refresh token نابێت لە source tree یان GitHub هەبن.

04 / SECURITY

Secrets و سنوورییەکانی پاراستن

ئەم ناوانە بۆ Edge Function ـی `notification-dispatch` ـن. لە وێبسایت، browser، migration، screenshot یان چاتدا هیچ value ـێکی ڕاستەقینە دانەمەزرێنە.

Provider secrets

META_ACCESS_TOKENWhatsApp
META_PHONE_NUMBER_IDWhatsApp
GOOGLE_REFRESH_TOKENGmail
GOOGLE_SENDER_EMAILGmail

Runtime controls

NOTIFICATION_WORKER_SECRETDispatcher

ئەگەر credential نەدانرابێت، item ـەکە retry/failed دەبێت و in-app notification ـی Staff OS بەردەوام دەمێنێت.

هیچ secret ـێک مەخە ناو ئەم پەڕەیەئەم documentation ـە تەنها ناوی variable و ڕێنمایی پیشان دەدات؛ value ـەکان تەنها لە Supabase Edge Function Secrets یان secret manager دابنێ.
05 / FLOW

Flow ـی ناردن و routing

Staff ئەولەویەتی یەکەمە؛ کڕیار تەنها بە opt-in و contact ـی پشتڕاستکراو پەیام وەردەگرێت.

01
Event`quote_requests` یان shipment event دروست دەبێت و database notification outbox ـی event key ـی یەکتا دروست دەکات.
02
ClaimDispatcher بە RPC ـی claim تەنها row ـە pending ـەکان وەردەگرێت و processing lock دروست دەکات.
03
Dispatchبەپێی channel پەیام بۆ Gmail یان WhatsApp دەنێرێت؛ unique key ـی `(event_key, channel)` duplicate ڕێگری لێدەکات.
04
Complete و fallback`sent` یان retryable failure تۆمار دەکرێت؛ in-app Staff OS notification هەروا دەمێنێت.
06 / VERIFY

پشکنینی کۆتایی و MCP boundary

پێش live activation، تاقیکردنەوە بە test mailbox و Meta test phone number ئەنجام بدە.

WhatsApp webhook

GET handshake، HMAC-SHA256، provider message ID و delivery event لە `notification_delivery_events` پشکنە.

MCP یان API؟

WhatsApp Cloud API و Gmail API خۆیان REST API ـن. Dispatcher ـی Edge Function production path ـە؛ MCP تەنها بە MCP server ـی ڕاستەقینە زیاد دەکرێت.
